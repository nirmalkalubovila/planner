# Project Rules — Legacy Life Builder

## No Emojis
Never use emojis anywhere in this web application — not in UI text, labels, badges, buttons, headings, placeholders, or any user-facing strings. Use Lucide icons or plain text instead.

## Version Update Notes
When asked to "make version update note" (or any spelling variant like "meke version update note"), retrieve the implementation details/walkthrough of the current/recent workspace session, and generate a concise, pointwise list of changes. This list must strictly focus on user-facing features (what they will see and experience), completely excluding backend, database, service, or other developer-only implementation details. Provide the proposed version number and release title as well.

## Mobile Responsiveness Rule
Every feature, UI change, modal, form, input, button, and layout MUST be fully responsive and adapt perfectly across all screen sizes — mobile devices (320px+), tablets, laptops, and desktops. Never allow horizontal overflow, text clipping, broken select dropdowns, or un-touchable elements on smaller screens.
